How it works
  1. Upload a photo or scan of your sheet music.
  2. Select the source key the music is currently written in.
  3. Select the destination key you want to transpose to.
  4. Click Transpose — the app sends the image to the GitHub Copilot API which reads the notes and returns them in ABC notation.
  5. The notes are automatically transposed and rendered side-by-side.
  6. Use the PNG button to download the transposed score.
